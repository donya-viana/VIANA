# VIANA — نسخه طراحی مستقل (Front-end)

این نسخه از صفر و مستقل از پروژه‌های قبلی ساخته شده است. برای اجرا به دیتابیس، Supabase یا سرور پایتون نیاز ندارد.

## اجرا
1. فایل ZIP را استخراج کن.
2. وارد پوشه `VIANA_FRESH` شو.
3. فایل `index.html` را با مرورگر باز کن. پیشنهاد: Chrome یا Firefox.
4. برای تجربه بهتر می‌توانی در VS Code افزونه Live Server را اجرا کنی.

## بخش‌های آماده
- پیام‌رسان با فهرست گفتگوها، فیلترها، جست‌وجو، صفحه گفتگو، ارسال پیام نمایشی، واکنش ایموجی و پنل اطلاعات مخاطب
- VIANA World با کارت انجمن‌ها و ترندها
- VIANA Market با ویترین محصول، دسته‌بندی، علاقه‌مندی و سبد خرید نمایشی
- تنظیمات چندبخشی: ظاهر، حساب، حریم خصوصی، امنیت، اعلان‌ها، گفتگوها، حافظه، زبان و دسترس‌پذیری، Icon Studio
- تم‌های Cherry Noir، Cyber Blue، Plum Lavender، Soft Light، Minimal و Pinterest Mood
- تنظیم تم در مرورگر با localStorage
- طراحی واکنش‌گرا برای دسکتاپ، تبلت و موبایل

## نکته مهم درباره امکانات
این یک پروتوتایپ تعاملی سمت کاربر است. پیام‌ها فقط در صفحه جاری نمایش داده می‌شوند و ارسال واقعی بین کاربران، ورود واقعی، تماس، ضبط/ارسال صدا، آپلود فایل، رمزنگاری، اعلان سروری، پرداخت، فروش واقعی و ذخیره ابری هنوز پیاده‌سازی نشده‌اند. تنظیمات امنیتی در این نسخه رابط نمایشی هستند و نباید به‌عنوان حفاظت واقعی حساب تلقی شوند.

## ساختار فایل‌ها
- `index.html` — ساختار صفحات و اجزای رابط
- `styles.css` — طراحی، تم‌ها و واکنش‌گرایی
- `app.js` — تعاملات نمایشی و مدیریت صفحات

## مرحله بعد
پس از تأیید چیدمان و امکانات، می‌توانیم رابط را به اجزای مستقل‌تر تقسیم کنیم و سپس API و دیتابیس را به‌صورت مرحله‌ای متصل کنیم، بدون اینکه طراحی از نو نوشته شود.
